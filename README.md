## How I work

- Architecture first, then automation: every system gets guardrails, fallbacks, and cost controls before it touches production.
- Business case attached: if it doesn't move a metric, it doesn't ship.
- Trust baked in: audit trails and usage metering from day one, so AI output is something a serious buyer can stand behind.
